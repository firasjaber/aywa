# Security policy

## Supported versions

Security fixes are provided for the latest `0.1.x` release. Older releases may
be fixed only when a safe, practical backport is available.

## Reporting a vulnerability

Please do not open a public GitHub issue for a suspected security vulnerability.
Use the repository's [private vulnerability-reporting form](https://github.com/firasjaber/aywa/security/advisories/new)
instead. Include the affected version, reproduction steps, impact, and any
proposed mitigation. Do not include secrets or personal recordings.

We aim to acknowledge reports within seven days and to share a triage decision
as soon as practical. These are goals, not response-time guarantees.

## Disclosure

Keep the report private while a fix is prepared. We will coordinate a release
and public disclosure with the reporter after users have a reasonable upgrade
path.
