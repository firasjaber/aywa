# Aywa 0.3.0

Aywa 0.3.0 adds configurable dictation shortcuts and reorganizes preferences into a dedicated Settings tab.

## Highlights

- Record a custom global hold-to-talk shortcut from Settings.
- Apply shortcut changes immediately without restarting Aywa.
- Keep the previous shortcut active when a proposed shortcut is invalid, unavailable, or cannot be saved.
- Reset the shortcut to `Ctrl` + `Alt` + `Space` at any time.
- Store the shortcut in the existing local `settings.json` alongside the History-saving preference.
- Use the new Settings tab for shortcut and History-saving controls, leaving the App tab focused on model and runtime status.
- Browse, copy, delete, and clear locally stored transcription History, or disable saving future transcripts.

## Compatibility and privacy

- Windows 10 and Windows 11 on 64-bit systems are supported.
- Existing settings files remain compatible and receive the default shortcut automatically.
- Audio transcription remains local after runtime and model setup.
- Temporary recordings are deleted after transcription; abandoned recordings are cleaned up on the next launch.
- History contains transcript text and metadata only when History saving is enabled.

## Known limitations

- The Windows installer is unsigned, so Windows may show an unknown-publisher or SmartScreen warning.
- Aywa requires a model and its local runtime files before dictation is available.
- A shortcut already owned by Windows or another application cannot be selected.
- Automatic pasting can be blocked by the destination application; the transcript remains on the clipboard when that happens.
